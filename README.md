# BehindWatch · 身后提醒

Windows 本地摄像头监测工具：检测其他人员出现、活动、停留，以及持续朝向屏幕附近的情况，默认通过安静的角落提示点提醒。没有声音提醒。

## 开始使用

1. 双击 `launch.cmd`。需要 Windows 10/11 x64、Python 3.12 x64 和摄像头。当前 Codex 环境可自动复用其 Python；其他机器需先安装 Python 3.12。
2. 首次运行创建项目内 `.venv`、安装依赖并下载两个固定版本模型；初始化需要联网，之后检测不需要联网。
3. 在下拉框选择摄像头，点击 **开始监测**。
4. 点击预览中属于你的检测框；也可以选择人员编号，再点 **这是我**。需要人工确认本人，不采集身份模板。
5. 可收起到系统托盘继续监测。托盘菜单可打开面板、暂停或退出；关闭主窗口会退出并释放摄像头。

默认提醒在主屏工作区右下角显示一个小圆点，6 秒后消失，不抢焦点、不显示文字：琥珀色表示其他人员或状态提醒，红色表示疑似看向屏幕。点击圆点打开面板查看事件。也可以在“提醒方式”中选择文字提示，依然无声音。

在 PyCharm 中请将解释器设为项目内 `.venv\Scripts\python.exe`。直接运行 `app.py` 时也会检查并切换到该项目环境，避免误用其他项目的 Python。缺少依赖会提示运行 `launch.cmd` 修复，不再误报为摄像头设备故障。

提示：关闭摄像头的背景替换/背景模糊效果，否则背景人员可能已被相机软件抹掉。Windows 摄像头权限需要允许桌面应用访问；本程序不会更改系统权限。

## 判断规则

- 人体检测与人脸补充检测结合，经过者不必正对摄像头。
- 其他人员连续出现约 0.8 秒后提醒；在画面中移动会标为活动。
- 持续停留约 4 秒后升级为停留提醒。
- 可辨识的人脸持续朝向屏幕附近约 2 秒后，提醒“有人可能看向屏幕”。
- 同一目标同等级提醒冷却 10 秒；高等级提醒可提前升级。
- 本人目标丢失超过 1 秒或跟踪交叉不明确时需重新校准。身份跟踪是几何近似，不能替代人脸认证。
- 采集与模型在独立进程中运行，不依赖浏览器前台。长时间无新帧会停止监测并明确提示；暂停时异常阻塞的采集进程最多等 3 秒后终止。
- 电脑睡眠、摄像头被占用或断开时无法监测。恢复后如已停止，请重新开始并校准。

## 数据与限制

运行时视频仅在本机内存中处理，不上传、不录像、不使用麦克风。界面最多保留本次运行 50 条文字事件，退出即清空。默认仅提醒，不自动锁屏或遮挡桌面。

**头部朝向不能确认眼睛正在看屏幕，更不能确认阅读。** 侧面、逆光、小人脸、遮挡、快速运动、多人交叉都可能漏检或误报。摄像头不可见的区域无法判断；多显示器时朝向摄像头也不等于朝向某块屏幕。本工具提供提示，不能保证没有旁观者。

本项目不使用 Windows Hello 做窥屏判断。同类实现与 Windows Hello 能力区别见 [RESEARCH.md](RESEARCH.md)。

## 开发与验证

```powershell
python -m unittest discover -s tests -v
.\.venv\Scripts\python.exe download_models.py
.\.venv\Scripts\python.exe app.py
```

`logic.py` 为不依赖模型的跟踪与时间规则；`vision.py` 为本地模型和独立采集进程；`app.py` 为 Tkinter 面板与托盘。`camera.py` 复用 SeatSentinel，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

模型、虚拟环境、图像和录像不提交 Git。安装脚本固定模型 URL 并验证 SHA-256；检测启动时也再次验证模型完整性。
