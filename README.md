# BehindWatch · 身后提醒

Windows 10/11 x64 本地摄像头监测工具。选择本人、忽略固定同事后，在其他人员持续走动时静音提醒；还可保护指定窗口或在离席时锁屏。

视频仅在本机内存中处理，不上传、不录像、不使用麦克风。它不能判断别人是否正在阅读屏幕，也不能保证没有旁观者。

## 下载与开始使用

从 [v0.1.3 发布页](https://github.com/zensoku142/BehindWatch/releases/tag/v0.1.3) 下载 `BehindWatch-Setup-v0.1.3-x64.exe`。安装包包含 Python 运行环境和本地模型，无需另装 Python；同页提供 `SHA256SUMS.txt`。

1. 安装后点击 **开始监测**；设备不正确时到 **设置 → 摄像头** 选择。
2. 点击 **选择本人**，再点击预览中自己的检测框。
3. 直接点击固定同事的检测框以忽略，再点一次取消忽略。未忽略人员持续走动才触发提醒。
4. 标题栏 X 收起到托盘继续工作；托盘可暂停或退出。`Ctrl+,` 打开设置，`Esc` 退出。

源码运行需 Python 3.12 x64，双击 `launch.cmd`。首次联网安装依赖、下载并校验模型，之后本地检测无需联网。请关闭摄像头软件的背景替换/模糊，否则后方人员可能不可见。

## 功能与设置

| 设置页 | 功能 |
| --- | --- |
| 摄像头 | 设备选择与刷新；持续监测或键鼠空闲后监测；空闲开启和在场复查间隔 |
| 锁屏与本人 | 可选离席锁屏；任意人脸/仅本人在场判断；注册、删除本机本人面容 |
| 窗口保护 | 指定目标；走动自动隐藏与手动恢复；浏览器顶部/右侧滚动条裁剪；鼠标移入/移出透明度；退出时关闭目标 |
| 提醒 | 静音系统通知或多屏角落提示点；测试提醒 |
| 常规 | Windows 登录自启；全局暂停快捷键；深浅/系统主题；五种界面语言 |
| 更新与关于 | 检查正式版本、阅读发布说明；安装版校验并安装更新；项目和反馈入口 |

设置自动保存，切换设置页、语言或主题不打断监测。每次启动仍需手动开启监测；注册面容后可自动识别本人，否则需重新选择。本人和同事的临时标记可以通过本次会话的人脸特征恢复。

- **自动锁屏默认关闭**：连续离席且键鼠空闲 60 秒后，先提示 5 秒；输入活动、人员返回或检测异常会取消。仅本人模式需要注册面容。
- **自动隐藏默认关闭**：先选择本人和目标窗口；其他未忽略人员持续走动时隐藏。人员离开或监测暂停不会自动恢复，需使用“恢复并关闭自动隐藏”。
- **透明度和裁剪不依赖摄像头**：Chrome、Edge、Firefox 的顶部高度通过 UI Automation 识别；无法识别时保留原窗口。
- **退出时关闭所选窗口默认开启**：正常退出先还原窗口，再发送关闭请求，目标应用可自行提示保存。收起到托盘不关闭；可在窗口保护页关闭这一选项。
- Windows 锁屏或息屏时释放摄像头，恢复后自动继续此前运行的监测；手动暂停不会自动恢复。
- 系统通知使用缓存的中国新闻网国内新闻标题；启动和每小时请求 RSS，点击打开原文。失败时使用中性提示。自动检查更新默认关闭，开启后每天请求 GitHub 正式版本。

完整操作、检测规则和兼容边界见 [使用说明](docs/USAGE.md)。

## 数据与限制

偏好保存在 `%LOCALAPPDATA%\BehindWatch\preferences.json`。注册面容仅保存 Windows 当前用户 DPAPI 加密的 128 维特征，不保存照片；会话中的同事特征不写磁盘。新闻和更新服务不接收画面、特征或监测结果。

遮挡、低帧率、相似外观、远处或侧面人脸都可能导致误报、漏检、标记丢失。注册面容不是活体检测或身份认证。仅保护所选窗口，不覆盖独立弹窗；强制结束程序无法恢复隐藏、透明度或裁剪状态，需要重启目标程序。具体进程内存和检测速度取决于机器与画面。

## 开发、构建与贡献

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
py -3.12 -m pip --python .venv/Scripts/python.exe install -r requirements-build.txt
.\.venv\Scripts\python.exe scripts/build_release.py --version 0.1.0
```

构建需要 Inno Setup 6，可用 `--iscc` 指定编译器路径。产物写入 `dist/` 和 `dist-installer/`，不提交 Git。Tag 触发 Windows CI，执行测试、打包、安装/覆盖安装自检后发布安装器及校验文件。
