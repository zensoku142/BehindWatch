# BehindWatch · 身后提醒

Windows 本地摄像头监测工具：选择本人后，检测其他人员是否持续走动；可手动标记固定同事为忽略。提醒静音，摄像头画面仅在本机处理。

主面板以摄像头预览为主；点击标题栏设置图标，在同一个窗口内切换设置页。点击 **返回面板** 返回，监测不会因此停止。按 Esc 退出程序；Ctrl+, 可打开设置。

界面使用 PySide6，与 TokenMeter 复用 Qt 主题令牌、控件样式、胶囊页签、开关和语言绑定：18px 窗口圆角、9px 控件圆角、Microsoft YaHei UI 字体及一致的字号与间距。

右上角的日/月按钮可直接切换深浅主题；**设置 → 常规 → 外观** 还支持跟随系统，以及简体中文、繁體中文、English、日本語、한국어。切换即时生效，不中断监测；设置自动保存在 `%LOCALAPPDATA%\BehindWatch\preferences.json`。下次启动会恢复摄像头、监测方式、锁屏、提醒和窗口保护选项；监测仍需手动启动并选择本人。目标窗口仅在标题和窗口类唯一匹配时恢复。

**设置 → 更新与关于** 可检查 GitHub 正式版本并显示发布说明。安装版可下载、校验并自动安装更新；源码版保留打开下载页。自动检查默认关闭，开启后每天检查一次；检查仅请求版本元数据，不发送摄像头画面。尚未发布的源码显示“开发版本”。

## 开始使用

1. Windows 10/11 x64 用户可从 [GitHub Releases](https://github.com/zensoku142/BehindWatch/releases) 下载 `BehindWatch-Setup-vX.Y.Z-x64.exe` 安装；安装包内置 Python 运行环境和三个本地模型，校验值见同一版本的 `SHA256SUMS.txt`。使用源码时双击 `launch.cmd`，需 Python 3.12 x64。
2. 源码首次运行会创建项目内 `.venv`、安装依赖并下载固定版本模型；初始化需要联网，之后检测不需要联网。
3. 主界面点击 **开始监测**，默认使用第一个可用摄像头；切换设备请打开 **设置 → 摄像头**。
4. 开始监测后，点击 **选择本人**，再点预览中自己的检测框。之后直接点击固定同事的检测框即可忽略，重复点击可取消忽略，无需再切换模式。普通点击本人框不会改变标记。其他未忽略人员持续走动时才提醒。选择时若有清晰正面人脸，会在本次监测的内存中保留 SFace 特征，编号丢失后连续 3 帧唯一匹配可自动恢复标记；没有清晰人脸时仅靠短时位置和衣着关联。停止并重新启动监测后，临时选择需重新设置。
5. 人脸注册可选。在 **设置 → 锁屏与本人** 将“在场判断”设为“仅本人”后，先选择本人，再点击 **注册当前本人**，正对摄像头采集 5 帧清晰面容；注册时请确保画面里只有自己。注册后可自动识别本人，也可手动选择。
6. 点击右上角 X 可收起到系统托盘继续监测。托盘菜单可打开面板、暂停或退出；按 Esc 也会退出并释放摄像头。

**设置 → 常规 → 开机自启** 可选择登录 Windows 后自动运行 BehindWatch，默认关闭。启用后为当前用户创建启动文件夹快捷方式；关闭后删除。该选择会自动保存。

Windows 锁屏（包括 Win+L）或显示器息屏时，运行中的监测会自动暂停并释放摄像头；解锁且显示器恢复后自动重新开启。手动暂停的监测不会自动开启。重新开启后，未注册本人面容时需要再次选择本人。

### 可选的离席锁屏与空闲摄像头模式

在 **设置 → 锁屏与本人** 可开启 **自动锁屏**。默认关闭，选择会自动保存。开启后，只有摄像头画面与模型正常、连续 60 秒未确认有人在场、键鼠至少空闲 60 秒、监测已启动 30 秒，并且 Windows 会话及显示器状态可确认时，才显示屏幕顶部不抢焦点的 5 秒提示。提示期间发现人脸或键鼠操作会取消；最终调用 Windows 锁屏接口前再次检查输入。每轮监测最多自动锁屏一次。

**在场判断** 可选“任意人脸”或“仅本人”。后者需要先注册本人面容，并要求连续两帧识别到同一位注册者；陌生人不会重置离席计时。摄像头读取失败、画面过期、模型异常或无法读取键鼠状态时不会自动锁屏。

摄像头默认 **持续监测**，与升级前一致。可切换为 **键鼠空闲后监测**：键鼠空闲达到设定阈值（默认 20 秒）才打开摄像头；连续确认有人在场 10 秒后释放设备，默认 60 秒后重新复查。恢复键鼠操作会清空预览并请求释放摄像头。模型留在进程中，不随设备开关反复载入。摄像头关闭期间不会判断离席锁屏，也不会提供实时走动提醒或窗口保护。当前项目尚无自动多人脸模糊功能，因此未增加相应互斥开关。

默认通过无声的 Windows 系统通知显示[中国新闻网国内新闻 RSS](https://www.chinanews.com.cn/rss/)中的近期标题。启动时后台抓取一次，之后每小时更新；检测事件只使用已缓存的标题，点击通知打开对应的新闻正文。通知源以“国内新闻速递”注册在当前用户的 Windows 通知设置中。新闻源不会收到摄像头画面或检测结果。抓取失败或没有近两天新闻时退回中性“系统状态”文案；系统决定通知的位置、停留时间以及是否显示。选择系统通知时，副屏右下角同时显示角落提示点；若系统托盘通知不可用，则每块屏幕都显示提示点。在 **设置 → 提醒** 可主动选择角落提示点：每块屏幕右下角的琥珀色小圆点表示走动提醒。点击同页的 **测试提醒** 可按当前方式显示示例，无需开启摄像头。

### 检测到其他人员时隐藏窗口

1. 直接在主界面标题栏的 **选择目标窗口** 下拉框选择需要保护的窗口；展开时自动刷新列表，也可在 **设置 → 窗口保护** 中选择（标题后附窗口句柄，可区分同名窗口）。
2. 开启 **其他人员走动时隐藏窗口**，开始监测并校准本人。也可以先开启自动隐藏，再选择目标窗口；未配置时保持等待，首次选定后自动生效。
3. 最新有效画面确认有未忽略的其他人员持续走动时，请求隐藏选中的整个窗口。默认不开启。
4. 点击 **恢复并关闭自动隐藏**，或使用托盘中的同名菜单恢复。取消勾选也会恢复；恢复后需重新勾选才能再次自动隐藏。

人员离开、本人校准丢失、暂停或摄像头故障时，已隐藏的窗口保持隐藏，防止短暂漏检导致内容重新露出。切换目标会恢复旧窗口并关闭开关；正常退出会先恢复本次隐藏的窗口；“退出时关闭所选窗口”默认开启，会再发送正常关闭请求（应用可能询问保存），可在窗口保护页关闭该选项。强制结束 BehindWatch 无法执行恢复，此时需要重启目标程序。

窗口列表参考 myth984 的可见窗口枚举方式，使用 Windows 原生隐藏接口。只保护所选窗口，不涵盖该程序另外打开的窗口或独立弹窗。未校准本人时不会触发隐藏；持续的人员框抖动仍可能误判为走动。高权限或特殊程序可能拒绝隐藏请求。

### 退出时关闭所选窗口

**设置 → 窗口保护 → 退出时关闭所选窗口** 默认开启，并记住开关状态。通过托盘“退出”或 Esc 真正退出 BehindWatch 时，先还原所选窗口的裁剪、透明度和显示状态，再发送正常关闭请求；目标程序若有未保存内容，仍由它显示保存提示。标题栏 X 仅收起到托盘，不关闭目标。关闭该开关后，退出时只还原窗口、保持打开。仅影响当前所选窗口，不强制结束目标进程。

### 鼠标移入 / 移出透明度

在 **设置 → 窗口保护** 选择目标窗口后，开启 **鼠标透明度**；也可以先开启，再选择目标窗口。保留 myth984 的两个独立滑动条：**移入**（初始 255）、**移出**（初始 0，即完全透明）。范围为 0～255，0 完全透明，255 完全不透明；拖动后即时生效，不需要开启摄像头。关闭设置面板不会停用透明度。

透明度与人员自动隐藏可以同时开启：检测隐藏优先，鼠标移入不会把隐藏的窗口显示出来；手动恢复窗口后继续按鼠标位置应用透明度。取消透明度勾选、切换目标或正常退出，会还原接管前的透明度和透明样式。透明度开关默认关闭；选择会自动保存。不要让两个工具同时调节同一个窗口的透明度，以免相互覆盖。

### 隐藏浏览器顶部和右侧滚动条

在 **设置 → 窗口保护** 选择浏览器后，开启 **隐藏浏览器顶部** 或 **隐藏右侧滚动条**，两个开关可独立使用，默认关闭。无需开启摄像头，可与鼠标透明度和人员自动隐藏同时使用。

- 自动读取标签栏、地址栏和书签栏的总高度，约每秒重新识别；不使用固定像素高度。适用于提供 UI Automation 信息的 Chrome、Edge、Firefox，识别失败或超时会保留原窗口。
- 右侧裁剪按显示器 DPI 对应的标准滚动条宽度计算；仍可使用鼠标滚轮和翻页键。自定义宽度的网页滚动条可能不能完全匹配。
- 裁掉的区域透出后方窗口，不会将网页内容向上拉伸。裁剪期间关闭 Mica 背景以避免白条；裁掉区域也按“鼠标移出”应用透明度。
- 关闭开关、取消或切换目标、正常退出会还原原有窗口区域和背景。标题栏关闭仅收起到托盘，会继续保持裁剪；强制结束程序无法恢复，需要重启目标浏览器。

升级源码后运行 `launch.cmd` 会安装与 myth984 相同的 `pywin32` 和 `comtypes` 依赖，用于原生裁剪及浏览器区域识别。无需同时运行 myth984。

在 PyCharm 中请将解释器设为项目内 `.venv\Scripts\python.exe`，这样调试器才能附着到应用本身。若误用其他项目的解释器且缺少依赖，直接运行 `app.py` 会在当前运行任务中等待项目 `.venv` 启动的应用退出；项目 `.venv` 也缺依赖时会提示运行 `launch.cmd` 修复。

提示：关闭摄像头的背景替换/背景模糊效果，否则背景人员可能已被相机软件抹掉。Windows 摄像头权限需要允许桌面应用访问；本程序不会更改系统权限。

## 判断规则

- 人员检测使用 OpenCV Zoo YOLOX（640×640 输入），跟踪直接调用 Supervision ByteTrack；保留低置信度框以延续已有目标。全画面生效，不预设通道位置，不要求路人露出正脸。MediaPipe 仅提供人脸关键点，SFace 用于恢复人工选择。
- 提醒需要先确定本人。其他未忽略人员在最长 1.8 秒的窗口内，至少观察 1 秒，三个时间段均有位置记录且持续同向移动才触发。门槛取归一化坐标的 1.25% 与身体框宽度的 45%（仅有人脸的补充目标为脸宽的 90%）中的较大值。短暂漏检保留历史，超过 1.5 秒没观测到该目标才重置；不再要求每秒至少 6 帧。仍属位移过滤，不是坐姿分类。
- 直接点击检测框可切换该同事的忽略状态；已忽略人员不触发走动提醒或自动隐藏。ByteTrack 维持人员编号，业务轨迹保留 3 秒以容忍短暂漏检；单帧推理超过 1 秒不再清空全部轨迹。更长时间丢失后，已缓存的会话人脸特征可用于恢复选择，摄像头暂停后也须重新确认。预览框仍随检测刷新。
- 同一人员的通知冷却时间为 10 秒。注册身份需清晰正脸进行特征比对；它不是活体检测或身份认证。
- 人体框用于走动判断、预览跟踪和可选的窗口保护；窗口保护也需要先确定本人。
- 采集与模型在独立进程中运行，不依赖浏览器前台。长时间无新帧会停止监测并明确提示；暂停时异常阻塞的采集进程最多等 3 秒后终止。
- 电脑睡眠、摄像头被占用或断开时无法监测。恢复后如已停止，请重新开始；仅窗口保护或手动注册时需要重新校准本人。

## 数据与限制

运行时视频仅在本机内存中处理，不上传、不录像、不使用麦克风。注册时只将 128 维特征模板用 Windows 当前用户 DPAPI 加密保存在 `%LOCALAPPDATA%\BehindWatch\owner_face.bin`，不保存照片；在 **设置 → 锁屏与本人 → 本人面容** 中可随时删除注册。默认仅提醒；可手动开启所选窗口自动隐藏或自动锁屏。

遮挡、快速运动、多人交叉或人员检测框抖动都可能使走动判断漏检、误报。人脸特征提取需要足够大且接近正面的人脸（当前至少 80 像素宽）；远处、侧脸或桌板遮挡下的同事可能无法建立会话特征，仍可能丢失标记。会话特征不写磁盘，不等同于设置中的本人面容注册；相似人脸、相似衣着也可能造成关联错误。摄像头不可见的区域无法判断；本工具提供提示，不能保证没有旁观者。

本项目不使用 Windows Hello 做窥屏判断。同类实现与 Windows Hello 能力区别见 [检测方案调研](RESEARCH.md)。

```powershell
python -m unittest discover -s tests -v

py -3.12 -m pip --python .venv/Scripts/python.exe install -r requirements-build.txt

```

源码布局见 [项目结构](PROJECT_STRUCTURE.md)。`core/` 存放监测和系统功能，`ui/` 存放界面与翻译，`updater/` 存放更新检查和安装逻辑。`core/camera.py` 复用 SeatSentinel，见 [来源与许可证](../THIRD_PARTY_NOTICES.md)。打包需 Inno Setup 6；生成的程序、安装器和 SHA-256 校验文件分别位于 `dist/`、`dist-installer/`。

模型、虚拟环境、本机截图和录像不提交 Git；正式文档插图可提交。安装脚本固定模型 URL 并验证 SHA-256；检测启动时也再次验证模型完整性。
