# BehindWatch v0.1.0

首个 0.1 正式版本，面向 Windows 10/11 x64。

## 功能

- 本地摄像头人员检测与跟踪：选择本人、点击忽略固定同事，其他人员持续走动时静音提醒。
- 系统新闻通知或多屏角落提示点；托盘常驻、全局暂停快捷键、登录自启。
- 可选本人面容注册与临时标记恢复；可选离席锁屏及键鼠空闲摄像头模式。
- 指定窗口自动隐藏、恢复、鼠标移入/移出透明度，浏览器顶部及右侧滚动条裁剪。
- 退出时关闭所选窗口可配置，默认开启；发送正常关闭请求，不强制结束目标进程。收起到托盘不关闭目标。
- 设置按摄像头、锁屏与本人、窗口保护、提醒、常规、更新与关于分组；五种语言、深浅/系统主题，设置自动保存。
- Windows 安装器内置运行环境和三个模型；安装版支持校验后安装正式更新。

## 收尾与优化

- 源码整理为 core、ui、updater、scripts、packaging、tests、docs；排除本机数据、模型权重、缓存及构建产物。
- 后台不解码预览，模型校验分块读取；冻结采集子进程不重复导入 Qt。
- 相同空白帧隔离测量中，采集模块工作集约从 510 MiB 降至 455 MiB；不是整应用长期峰值承诺。
- 安装器采用更高压缩级别；同内容对照减少约 3.3 MiB。保留检测功能所需的模型及原生依赖。
- README、详细使用说明、提交边界、性能测量及第三方许可证与实际实现同步。

## 验证

- 本机 135 项 unittest 通过，包含设置分组、五种语言最小窗口布局、监测状态、偏好、原生窗口保护与更新边界。
- 设置页截图核对通过。
- 冻结程序自检通过：独立子进程初始化模型、空白帧检测/跟踪、Qt 界面初始化和退出；未开启真实摄像头。
- 文档本地链接、Git 忽略边界与差异空白检查通过。

## 下载与限制

下载 `BehindWatch-Setup-v0.1.0-x64.exe`；使用同页 `SHA256SUMS.txt` 校验 SHA-256。无需安装 Python，安装后本地检测可离线运行。新闻 RSS 和可选更新检查需要联网。

视频不上传、不录像、不采集麦克风。面容模板由 Windows 当前用户 DPAPI 加密保存在本机，不保存照片。未进行真实摄像头长期稳定性、跨设备准确率或全部 DPI/多屏组合验收；遮挡、快速运动和相似外观仍可能误报、漏检。强制结束程序不能还原外部窗口状态。
