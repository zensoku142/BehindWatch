# BehindWatch v0.1.1

Windows 10/11 x64 修订版本。

## 修复

- 主窗口收起到系统托盘后，再次启动 BehindWatch 会请求已运行的实例显示监测面板，便于找到窗口并正常退出。
- 原有单实例限制、托盘菜单和退出清理行为保持不变。若原实例尚未准备好接收请求，仍显示“已在运行”提示。

## 验证

- 本地 136 项 unittest 通过，包括 Windows 事件通知测试及界面测试。
- 安装包构建、冻结程序自检和覆盖安装检查由发布工作流执行。

## 下载

下载 `BehindWatch-Setup-v0.1.1-x64.exe`，使用同页 `SHA256SUMS.txt` 校验 SHA-256。安装新版本前，可从托盘菜单退出旧版本；找不到托盘图标时，可在任务管理器中结束 `BehindWatch.exe`。
