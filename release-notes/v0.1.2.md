# BehindWatch v0.1.2

Windows 10/11 x64 修订版本。

## 修复

- 修复点击“下载并安装”后主程序退出，但安装器可能未正常完成的问题。独立更新器现在从安装目录外运行，避免安装时覆盖正在使用的更新器。
- 安装阶段显示进度窗口；失败时显示错误，并在更新缓存目录生成安装日志，便于排查。

## 验证

- 本地 138 项 unittest 通过，包含更新器运行位置和安装器启动参数测试。
- 安装包构建、冻结程序自检、覆盖安装和更新器交接检查由发布工作流执行。

## 下载

下载 `BehindWatch-Setup-v0.1.2-x64.exe`，使用同页 `SHA256SUMS.txt` 校验 SHA-256。旧版应用内更新器尚无本次修复，请先退出旧版，再手动运行此安装包完成升级。用户设置保存在独立目录，覆盖安装不会删除。
