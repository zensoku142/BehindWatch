# BehindWatch v0.1.3

Windows 10/11 x64 修订版本。

## 修复与调整

- 改用 YOLO26s 人体检测，并使用 ONNX Runtime 执行模型，修复 OpenCV DNN 在实际人物画面中产生重复错框或报错停止监测的问题。
- 走动判定参考身体框底部和边界的持续移动，降低静坐时检测框形变造成的误提醒，并容忍经过时人体框逐渐变化。
- 更新模型下载校验、运行依赖和安装包资源；现有 ByteTrack 跟踪、本人选择和提醒接口保持不变。

## 验证

- 本地 141 项单元测试通过。
- 本地人物样本连续 8 帧均检出 1 个人体目标并保持跟踪；完整检测链路连续 3 次得到同一人体框并关联人脸。
- Windows 冻结程序已构建，`--smoke-test` 退出码为 0。真实工位的静坐误报率和人员经过召回率尚未量化。

## 下载

下载 `BehindWatch-Setup-v0.1.3-x64.exe`，使用同页 `SHA256SUMS.txt` 校验 SHA-256。安装前请先从系统托盘完全退出旧版。模型和源码授权信息见仓库的 `THIRD_PARTY_NOTICES.md`。
